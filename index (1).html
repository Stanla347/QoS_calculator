Fungsi & Rumus Asli

Contoh angka memakai data Anda

Throughput

Mengukur kecepatan transfer data efektif: total byte yang berhasil diterima dibagi lamanya pengamatan (timespan), lalu dikonversi ke bit.

Throughput (bit/s) = (Jumlah Bytes ÷ Timespan) × 8

Contoh

8.346.343 ÷ 46,543 = 179.325,4195 byte/s 179.325,4195 × 8 = 1.434.603,356 bit/s

Catatan

  • Satuan hasil: bit/s (÷1000 = kbps, ÷1.000.000 = Mbps).
  • Indeks TIPHON memakai persentase terhadap bandwidth: Throughput ÷ Bandwidth × 100.

Packet Loss

Mengukur proporsi paket yang gagal sampai tujuan. Semakin kecil semakin baik.

Packet Loss (%) = ((Paket dikirim − Paket diterima) ÷ Paket dikirim) × 100

Contoh

((10553 − 10546) ÷ 10553) × 100 = 0,0663 %

Catatan

  • Paket hilang = dikirim − diterima (di contoh: 7 paket, yaitu baris “Previous segment not captured” di Wireshark).
  • Hasil 99,93% bila dihitung dari diterima ÷ dikirim adalah tingkat penerimaan, bukan packet loss.

Delay

Rata-rata waktu tunda antar paket. Di Excel, delay tiap paket adalah selisih waktu paket berikutnya dengan waktu paket saat ini.

Delay paket = time 2 − time 1 Delay (ms) = (Total Delay ÷ Jumlah Paket) × 1000

Contoh

46,543364 ÷ 10.553 = 0,004410439 detik 0,004410439 × 1000 = 4,410439 ms

Catatan

  • Total Delay = Σ delay seluruh paket (detik); delay paket = Time paket berikutnya − Time paket ini.
  • Jumlah Paket = banyak baris pada kolom No.

Jitter

Variasi delay antar paket berturut-turut. Di Excel: delay paket berikutnya dikurangi delay paket saat ini.

Jitter paket = delay 2 − delay 1 Jitter (ms) = (Total Jitter ÷ Jumlah Paket) × 1000

Contoh

0,0209389 ÷ 10.553 = 1,98417E-06 detik 1,98417E-06 × 1000 = 0,00198417 ms

Catatan

  • Mode “bertanda” = persis Excel; mode “absolut” tersedia saat impor CSV.

Indeks Rata-rata (Standar TIPHON)

Setiap parameter dikonversi ke indeks 1–4 berdasarkan Tabel Indeks, lalu dirata-rata.

Indeks rata-rata = (Indeks Throughput + Indeks Packet Loss + Indeks Delay + Indeks Jitter) ÷ 4
  • 3,8 – 4 : Sangat Memuaskan · 3 – 3,79 : Memuaskan · 2 – 2,99 : Kurang Memuaskan · 1 – 1,99 : Jelek

Cara Konvensional

Wireshark + kalkulator/Excel, langkah ringkas
Throughput
  1. Buka file hasil capture di Wireshark.
  2. Menu Statistics → Capture File Properties.
  3. Catat Bytes dan Time span, s pada bagian Measurement (atau di Excel: =SUM(kolom Length) pada raw data).
  4. Bagi: Bytes ÷ Time span → byte/s.
  5. Kalikan 8 → bit/s. Bagi 1000 untuk kbps.
  6. Untuk indeks: bit/s ÷ (Bandwidth × 1.000.000) × 100 lalu cocokkan ke tabel.
Packet Loss
  1. Buka capture di Wireshark tanpa filter; catat jumlah Displayed di status bar = paket dikirim.
  2. Ketik display filter tcp.analysis.lost_segment lalu Enter; catat Displayed = paket hilang.
  3. Paket diterima = dikirim − hilang.
  4. Hitung ((dikirim − diterima) ÷ dikirim) × 100 → %.
  5. Cocokkan dengan Tabel Indeks.
Delay
  1. Di Wireshark: File → Export Packet Dissections → As CSV (raw data). Atur dulu View → Time Display Format → Seconds Since Beginning of Capture. File ini juga yang diunggah di halaman Impor Raw Data.
  2. Di Excel: kolom time 1 = Time baris ke-n, time 2 = Time baris ke-(n+1).
  3. Kolom delay = time 2 − time 1, isi ke seluruh baris.
  4. Total delay = SUM(kolom delay).
  5. Jumlah paket = COUNT(kolom No.).
  6. Rata delay = Total ÷ Jumlah paket (detik); kalikan 1000 → ms.
Jitter
  1. Gunakan kolom delay dari langkah Delay.
  2. delay 1 = delay baris ke-n, delay 2 = delay baris ke-(n+1).
  3. Kolom jitter = delay 2 − delay 1.
  4. Total jitter = SUM(kolom jitter).
  5. Rata jitter = Total ÷ Jumlah paket (detik); kalikan 1000 → ms.
Indeks rata-rata
  1. Ubah tiap hasil menjadi indeks 1–4 memakai Tabel Indeks.
  2. Jumlahkan keempat indeks, bagi 4.
  3. Tentukan kategori: 3,8–4 Sangat Memuaskan, 3–3,79 Memuaskan, 2–2,99 Kurang Memuaskan, 1–1,99 Jelek.
